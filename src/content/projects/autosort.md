## Overview

Autosort is a small, focused desktop tool for the unglamorous task of copying and organizing large batches of files without living in the terminal. It wraps a genuinely simple idea in a clean Qt interface so that someone who isn't comfortable with the command line can still move hundreds of files reliably.

It's the project that taught me most about shipping software other people actually use — handling edge cases like duplicate names and interrupted copies, writing docs, and responding to issues from strangers who found it useful enough to star.

## Key Highlights

- Intuitive Qt GUI that hides the complexity of bulk file operations
- Handles duplicate names, nested folders, and large batches gracefully
- Distributed as free software with a demo and clear documentation
- Grew an organic user base to 30+ GitHub stars
