# Portfolio

My personal website: [vihdutta.com](https://vihdutta.com).

Built with React, TypeScript, Vite, and Tailwind CSS.

```bash
nvm use
npm install
npm run dev
```

Edit site content in `src/content/`. Project and contribution writeups are Markdown files.

Run `npm run check` before committing. Pushing to `main` deploys to GitHub Pages.

See [DEPLOYMENT.md](DEPLOYMENT.md) for deployment details.
